# 阅读路径

> 面向第一次进入本知识库的读者。每条路径只保留完成一个具体目标所需的文章；读完后再回到[知识库总索引](<知识库总索引.md>)按主题继续查阅。

## 路径一：第一次把 AI 用成可交付的助手

**适合谁：** 会和 AI 聊天，但还没有稳定做事方法的读者。

**读完能得到：** 一套从任务描述、上下文输入到结果验收的最小闭环。

1. [Codex 新手上手：从界面到第一个高质量任务](<../01-工具教程/01-Codex 新手上手：从界面到第一个高质量任务/01-Codex 新手上手：从界面到第一个高质量任务.md>)：先学会把任务说清楚。
2. [别再只会问 AI：把它变成可交付工作流](<../03-好文方法/08-别再只会问 AI：把它变成可交付工作流/08-别再只会问 AI：把它变成可交付工作流.md>)：把一次提问变成可复用流程。

**预计阅读：** 35—50 分钟。

## 路径二：把 Codex 用进长期工作

**适合谁：** 已经完成过一次任务，想把经验沉淀为稳定工作方式的读者。

**读完能得到：** 可复用的规则、Skill 和知识库维护方法。

1. [Codex 进阶提效：配置、权限、复用与自动化](<../01-工具教程/02-Codex 进阶提效：配置、权限、复用与自动化/02-Codex 进阶提效：配置、权限、复用与自动化.md>)：建立可控的日常使用环境。
2. [AGENTS.md 深度模板：让 Codex 按团队规则工作](<../01-工具教程/04-AGENTS.md 深度模板：让 Codex 按团队规则工作/04-AGENTS.md 深度模板：让 Codex 按团队规则工作.md>)：把重复要求写成项目规则。
3. [Codex 插件与 Skill 指南：把常用能力沉淀进工作流](<../01-工具教程/05-Codex 插件与 Skill 指南：把常用能力沉淀进工作流/05-Codex 插件与 Skill 指南：把常用能力沉淀进工作流.md>)：把高频流程固化成可调用能力。

**预计阅读：** 45—70 分钟。

## 路径三：理解 Agent，并跑通第一个工具型任务

**适合谁：** 想知道 Agent、Skill、工具调用分别解决什么问题的读者。

**读完能得到：** 不依赖术语堆砌的 Agent 与 Skill 基础认知，以及一个可继续实践的工具入口。

1. [Codex 智能体与 Skills 中文参考手册](<../01-工具教程/09-Codex 智能体与 Skills 中文参考手册/09-Codex 智能体与 Skills 中文参考手册.md>)：建立 Agent 与 Skill 的基本概念。

**预计阅读：** 20—35 分钟。

## 路径四：用案例学习“做完并验收”

**适合谁：** 不想只看概念，更想参考完整任务过程的读者。

**读完能得到：** 从失败排查、需求拆分到成果验收的案例参照。

1. [Codex 实战案例：从失败测试到可验证修复](<../05-案例实战/03-Codex 实战案例：从失败测试到可验证修复/03-Codex 实战案例：从失败测试到可验证修复.md>)。
2. [第一次做微信小程序：用 weStudy 看懂从导入到 AI 功能的开发闭环](<../05-案例实战/06-第一次做微信小程序：用 weStudy 看懂从导入到 AI 功能的开发闭环/06-第一次做微信小程序：用 weStudy 看懂从导入到 AI 功能的开发闭环.md>)。

**预计阅读：** 60—100 分钟。先选一篇照着做，不必一次读完。
