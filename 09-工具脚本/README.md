# 工具脚本

所有脚本均从仓库根目录执行；脚本只检查、重建索引或写入明确的报告，不提交、不推送。

| 目录 | 用途 | 主要入口 |
| --- | --- | --- |
| [01-发布校验](<01-发布校验/>) | 发布前重建与边界校验。 | `python 09-工具脚本/01-发布校验/一键发布检查.py` |
| [02-内容去重与归档](<02-内容去重与归档/>) | 正式文章去重、外部原文归档与内容索引重建。 | `node 09-工具脚本/02-内容去重与归档/检查内容重复度.mjs --candidate <文件>` |
| [03-技能接入](<03-技能接入/>) | 按需接入外部 canonical `article-Skill`，不在项目内维护版本锁定或适配配置。 | `python 09-工具脚本/01-发布校验/文章统一检查.py --id <编号> --strict` |

## 日常命令

```powershell
python 09-工具脚本/01-发布校验/一键发布检查.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/verify.ps1 -Deep
node 09-工具脚本/02-内容去重与归档/重建内容库索引.mjs
```

> `03-技能接入/` 是配置与锁定记录，不是第二套视觉规则或生成链。
