# visual_spec 模板

| 字段 | 内容 |
| --- | --- |
| asset_id |  |
| asset_role | cover / inline_diagram / screenshot / social_card |
| reader_question | 这张图帮读者解决什么理解问题？ |
| information_gain | 如果删掉这张图，读者会少理解什么？ |
| content_binding | 对应正文段落 / 小节 |
| template_id | 选择模板库中的模板 |
| canvas | 例如 1600 × 900 |
| safe_area | 四边安全区、标题区、卡片区 |
| grid | 列数、行距、卡片数量、阅读顺序 |
| style_tokens | 背景、主色、辅助色、圆角、阴影 |
| typography | 标题、卡片标题、说明文字字号和字重 |
| text_budget | 每个文字块的最大字数和最大行数 |
| components | 主视觉、卡片、连线、标签、底部提示等 |
| source_rights | AI 视觉 / 自绘 / 官方截图 / 用户素材及权限 |
| preview_requirements | 100% 原图、50% 缩略图、375px 手机宽 |
| blocked_if | 裁切、挤字、撞线、乱码、风格漂移等阻断条件 |
| human_review | 是否需要人工确认 |
