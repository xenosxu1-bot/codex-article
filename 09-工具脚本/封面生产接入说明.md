# 封面生产接入说明

本项目只保存文章、素材、元数据、资产登记和检查入口，不再保存独立封面或正文插图视觉规则、图片路由或渲染器。

## 生产边界

1. 在 `article-Skill` 中完成文章绑定、视觉 Brief、候选方向、人工选择和生成前检查。
2. 模型生成的像素保持无文字；中文标题、标签和正文图节点由确定性后期排版完成。
3. 人工审核后，将入选封面回写本项目的 `08-素材库/图片/文章封面/`，将入选正文插图回写 `08-素材库/图片/正文插图/`，并同步文章元数据和资产登记表。
4. 发布前运行：`python 09-工具脚本/文章统一检查.py --id <文章编号> --strict --skill-root ..\article-Skill`。

旧版独立封面模板与渲染器不再保留在本项目中；如需追溯通用规则演进，以 `article-Skill` 的 Git 历史为准。
