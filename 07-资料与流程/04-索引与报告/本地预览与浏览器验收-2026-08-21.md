## 下一次验收入口

```powershell
python 09-工具脚本/01-发布校验/生成文章预览.py --article "<文章 Markdown 绝对路径>" --output ".tmp/preview/<文章编号>.html"
```

生成后应在可渲染浏览器中逐篇检查：

1. 图片是否实际显示，而不是显示 Markdown 链接或裸路径；
2. 标题、段落、列表、代码块和表格是否有正常间距；
3. 手机宽度下是否出现横向滚动、文字截断或图片溢出；
4. 链接是否能点击，特殊字符和中文标点是否乱码；
5. 文章开头、转折、结尾和图片位置是否符合目标平台的阅读节奏。
